# soli

Tools for giving AI agents useful context and making their sources easier to check.

- **[Context Layer](https://github.com/solisolsoli/context-layer)** connects local Markdown notes and Obsidian vaults to AI tools. Retrieve original passages, follow explicit note links, and carry source-linked decisions between sessions through a CLI and MCP server.
- **[TimelineXray](https://github.com/solisolsoli/timelinexray)** helps people and agents study X’s public recommendation code with commit-pinned citations, exact source spans, and findings that flag changed evidence. An independent, unofficial research tool.

Both projects are in alpha. Their documentation describes what has been tested and where the limits remain.
